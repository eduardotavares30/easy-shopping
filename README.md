## :open_file_folder: Sobre o Projeto

O Easy Shopping Via Mobile é um projeto que foi desenvolvido durante as aulas lecionadas pelo professor Rodolfo Mori no curso do <a href="https://aulas.devclub.com.br/">DevClub</a>, e consiste em uma landing page moderna que simula uma experiência de compras em computadores e dispositivos móveis.

<br>

> Este projeto foi desenvolvido com foco em:

  - Prática utilizando recursos do HTML
  - Organização do código com HTML Semântico
  - Estilização moderna com CSS
  - Responsividade para computadores e celulares
  - Posicionamento de elementos
